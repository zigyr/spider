# 2026-08-01 学习日志

## 抖音喜欢视频 — DrissionPage 接口监听

- **新建** `-projects/视频/抖音喜欢视频/20260801/`
- 使用 `tab.listen.start("v1/web/aweme/post/")` 拦截抖音用户视频列表 API
- 确认浏览器接管方案可行：登录态、Cookie、JS 签名均由浏览器自动处理，无需手动生成 `a_bogus` / `x-secsdk-web-signature`
- 解析 Response 结构：`aweme_list`（视频数组）、`max_cursor`（分页游标）、`has_more`（是否有下一页）
- Payload 参数分类为三层：业务参数（`sec_user_id`, `max_cursor`, `count`）、浏览器环境参数（风控指纹）、签名参数（动态生成，不可复用）

## 已证伪方案

- `requests` 直接拼接 `max_cursor` 复现接口 → 403，签名与参数不匹配
- `tab.scroll.to_bottom()` / `tab.scroll.down()` → 不触发新的 API 请求，抖音非简单滚动加载

## 当前卡点

- `max_cursor` 分页机制已确认，但无法程序化触发下一页请求
- 下一步方向：通过浏览器 DevTools Network → Initiator 定位前端分页函数，再用 `tab.run_js()` 调用
